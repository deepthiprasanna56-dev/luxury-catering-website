# Gather & Grain — Luxury Artisanal Catering Website

A modern, responsive, high-end catering web application designed and developed with **React 19**, **Vite 8**, and **Tailwind CSS**.

---

## ✦ Features & Sections

- **Announcement Strip**: Highlighting seasonal menu availability and direct consultation CTA.
- **Sticky Glassmorphism Navbar**:
  - Live active section indicator highlighting your current position on the page.
  - Smooth native anchor scrolling with custom header offset.
  - Responsive mobile drawer navigation with animated toggle.
- **Editorial Hero Section**:
  - Editorial typography and evocative storytelling copy.
  - High-resolution catering visuals with framed offset border.
  - Continuous 360° rotating botanical brand seal.
  - Social proof avatar stack with 5.0-star rating across 650+ celebrations.
  - Animated bouncing scroll indicator.
- **Continuous Marquee Ticker**:
  - Infinite smooth banner showcasing culinary values and organic farm-to-table ethos (pauses on hover).
- **About Us Section**:
  - Brand story rooted in regenerative farm sourcing and scratch cooking.
  - Tilted polaroid note card and floating farm verification badge.
  - Three core culinary pillars (Regenerative Sourcing, Bespoke Curation, White-Glove Hospitality).
  - Four key metric counters (650+ Celebrations, 100% Farm-Fresh, 12 Award-Winning Chefs, 5.0 Host Satisfaction).
- **Catering Services Section (Interactive Cards)**:
  - 4 tailored catering services (Weddings, Private Dinners, Corporate Galas, Cocktails & Grazing).
  - Guest capacity tags, feature highlights, and interactive "Inquire for this service" buttons that pre-populate the booking form.
- **Menu & Food Categories Section**:
  - Interactive course category filtering (All Dishes, Canapés & Starters, Plated Mains, Family Feasts, Desserts & Sweets, Artisan Drinks).
  - Quick dietary filter tags (All, Gluten-Free, Vegetarian, Dairy-Free).
  - Dish cards with food photography, zoom hover effects, price per person, dietary chips, and "Request in Tasting" CTA.
- **Events & Packages Section**:
  - Mood photography banner capturing the warmth of gathered tables.
  - 4 comprehensive event packages with course breakdowns, guest pricing, and complete inclusions.
  - Featured ribbon on signature packages with direct "Select This Package" buttons that auto-fill the booking inquiry.
- **Image Gallery with Lightbox Modal**:
  - Dynamic masonry-style grid with category filter chips (All, Table Styling, Plated Art, Celebrations, Craft Cocktails).
  - Smooth hover zoom and gradient caption overlays.
  - Fullscreen Lightbox Modal preview with keyboard navigation (ESC, Arrow keys), previous/next controls, and image counter.
- **Customer Testimonials Carousel**:
  - Automated slide progression with pause on mouse hover / focus.
  - Manual previous/next arrow buttons and clickable dot navigation.
  - Verified host details, event types, venue locations, and 5-star ratings.
- **Frequently Asked Questions (FAQ) Accordion**:
  - Interactive accordion addressing tasting sessions, booking timelines, dietary accommodations, and tableware rentals.
- **Contact & Booking Form UI**:
  - Comprehensive booking form with host name, email, phone, HTML5 date picker with minimum date constraint, event occasion dropdown, guest size selector, package preference, and special dietary notes.
  - Instant validation and celebratory confirmation state with summary recap.
  - Direct studio contact information (phone, email, physical studio address, hours, Instagram banner).
- **Footer Section**:
  - Brand wordmark with mission statement.
  - Quick navigation and offerings links.
  - Seasonal Table Notes newsletter subscription form with instant feedback.
  - Custom SVG social media icons (Instagram, Pinterest, Facebook, LinkedIn).
  - Smooth back-to-top button.

### 2. Production Build


### 3. Linting

```bash
npm run lint
```
